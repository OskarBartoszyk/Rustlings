# Rust for Python developers (rustlings-style)

32 short exercises. Each file in `exercises/` has: lesson in comments -> demo code -> TASK to complete.

    python3 check.py        # checks exercises in order, stops at the first unfinished one
    python3 check.py 7      # run only exercise 07
    python3 check.py list   # progress overview

Edit a file in `exercises/`, run `check.py`, read the compiler errors (they are very helpful!).
`solutions/` has the reference answers - peek only if you're really stuck.
